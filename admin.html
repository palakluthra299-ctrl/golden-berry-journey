Website switches

Ye buttons turant site pe asar karte hain (save dabane ke baad).

Cashfree payment ON = site pe CHECKOUT NOW (online payment / COD) dikhega.
OFF = sirf WhatsApp wale options dikhenge. Server mode: …
speacial20 offer ON = cart me "Apply Coupon" aur 20% OFF dikhega.
OFF = coupon chhup jayega aur code kaam nahi karega.
